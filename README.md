# Simon Says Game 🎮

A fun memory game built using HTML, CSS, and JavaScript.

## 📌 Features
- Random color sequence generation
- User input validation
- Score tracking
- Game Over and Restart functionality
- Responsive design

## 🛠️ Technologies Used
- HTML5
- CSS3
- JavaScript

## 🚀 How to Play
1. Press any key to start the game.
2. Watch the color sequence carefully.
3. Repeat the same sequence by clicking the buttons.
4. The sequence gets longer after every correct round.
5. The game ends if you click the wrong button.
